Game

Magic Sort

Playable right here · 16:9 itch.io ↗ Source ↗

A water sort puzzle I made on my own, where most of the work went into how each move feels.

Game feel

A tube dips and then lifts when you pick it, shakes when the move isn't allowed, pours along an arc and bounces once it's full. Every level slides in tube by tube so you can read the board before you play.

Code

No DI framework: one composition root wires everything, and a small event bus keeps the game logic and the visuals apart. All animation timings sit in one ScriptableObject, so I can tune the feel without touching code. Phones get haptic feedback on iOS and Android.

Unity 6 · C# · DOTween

Procedural puzzle · Unity 6 · C#

Drag oddly shaped pieces onto a grid made of triangles. There are no hand-made levels: each one is generated when you start it, by splitting the grid with a flood fill. Has undo, a level editor window and unit tests.
